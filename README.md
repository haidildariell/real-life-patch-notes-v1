Entry for the make.fun bounty [Real-Life Patch Notes: The Comedy Changelog](https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d).

The program writes one line — a software patch note for a bug in real life
or human biology, in the terse register of a real release note — to
`/output/entry.txt`:

> v2.3.1: fixed a bug where the phone vibrated in a pocket containing no phone.

Run it with `python3 main.py` (Python 3.13). It writes exactly one line of
77 characters, no trailing newline.
